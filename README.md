# CarMarket SPB

Маркет тачек от медийных перекупов Петербурга.

| Продавец | Тема | Статус |
|---|---|---|
| **Lex Auto** - [@lexautospb13](https://t.me/lexautospb13), 229K | `neon`: маджента/фиолет/золото | 22 машины из канала |
| **Перекупчино** (Вова, @pak_info) - [@perekupchino_777](https://t.me/perekupchino_777), 257K, [IG](https://www.instagram.com/perekupchino/) | `grunge`: ч/б, острые углы, красный акцент | 15 в продаже + 2 проданные, самые свежие из закрытого канала "Перекупчино Авто" (153K) |

Идея: перекупы продают машины через Telegram-каналы, где их сложно искать. Здесь каждая машина - отдельное объявление с поиском, фильтрами, зазором до рынка, состоянием кузова, счётчиком спроса, задатком и торгом. У каждого продавца своя витрина с логотипом, цветами и рамкой номера.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: поиск, партнёр недели, каталог с фильтрами, как купить, продавцы |
| `car.html?id=<slug>` | Машина: галерея, цена и шкала рынка, задаток, торг, схема окрасов, проверки, комплектация, посты про эту машину из Telegram |
| `seller.html?id=lex-auto` | Витрина продавца: шапка с фото, соцсети, анонс, лента канала, Instagram, все машины |
| `bloggers.html` | Для блогеров: было в канале / стало на маркете, преимущества, заявка |

Статика без сборки: HTML + `assets/css/style.css` + `assets/js/app.js`. Шрифты Unbounded + Manrope (Google Fonts).

## Данные

- `assets/js/cars.js` - машины Lex Auto, **генерируется** `tools/build_data.py`, руками не править.
- `assets/js/cars-perekupchino.js` - машины Перекупчино, генерирует `tools/build_perekupchino.py <папка> 15 2` из постов канала "Перекупчино Авто" (posts.json + фото). Берёт последние 17 объявлений "В ПРОДАЖЕ", 2 самых старых из них помечает проданными. В каждой машине телефон менеджера и ссылка на отчёт Автотеки из поста.
- `assets/js/sellers.js` - продавцы: бренд, `theme` (`neon` / `grunge`), цвета, ссылки, анонсы. `onboarding: true` - витрина без машин с подпиской на первую машину. Новый продавец = новая запись + папка `assets/img/sellers/<id>/`.
- После правок CSS/JS поднимайте `?v=N` в подключениях в HTML, иначе браузеры возьмут старое из кэша.
- `assets/img/cars/<slug>/` - фото (00 = обложка из анонса, `card.jpg` = превью для карточки).

Обновить машины из канала:

```sh
tools/scrape_tg.sh lexautospb13 25 /tmp/tg
python3 tools/parse_tg.py /tmp/tg tools/posts.json
# скачать фото постов в <photos>/<listing_id>/NN.jpg и x<postid>_0.jpg (см. LISTINGS в build_data.py)
python3 tools/build_data.py tools/posts.json <photos>
```

В `build_data.py` словарь `LISTINGS` связывает пост-объявление с постом-анонсом (обложка) и скриншотами отчётов.

## Что в демо условно

- Статусы "Продана" / "Задаток внесён" (`DEMO_STATE` в build_data.py).
- "Хотят купить" и "смотрят сейчас" считаются от реальных просмотров поста, но не живые.
- Схема окрасов: продавец пишет количество окрасов, но не где они. Расположение примерное, на странице это подписано.
- Задаток и торг: формы работают, но деньги не списываются; заявка дублируется в Telegram продавцу через `t.me/<username>?text=`.
- Вырез Лёхи (`lexa-cutout.png`) из поста 163005 (фото 800px, `tools/cutout.swift`, Apple Vision), ноги растворяются маской. Лучше заменить на фотосессию в полный рост на однотонном фоне.

## Характеристики и фильтры

`enrich()` в app.js дополняет каждую машину: кузов и привод по модели (если в посте не сказано), руль (правый только если написано), цвет (только если продавец написал "в ... цвете"), бензин по умолчанию, если указан объём без слова "дизель". Фильтры: продавец, марка, цена, зазор, коробка, кузов, двигатель, привод, руль, цвет, год, важные пункты.

## Мобильная версия

- Нижнее меню из 5 пунктов (Главная, Поиск, Продать, Избранное, Продавцы), на странице машины вместо него панель цены и задатка.
- Каталог на телефоне плиткой в 2 ряда (переключатель вида в панели над лентой, запоминается), панель с сортировкой прилипает при скролле.
- Кнопки и поля от 44px, отступы под вырез и полоску жестов (`env(safe-area-inset-*)`).
- PWA: `manifest.webmanifest`, иконки `assets/img/icon-*.png`, `sw.js` (страницы network-first, фото cache-first). Плашка "Установить" на Android, подсказка "На экран Домой" на iPhone.

## Загрузочный экран

Инлайн в `<head>`/`<body>` каждой страницы (`#boot`), чтобы появлялся до загрузки CSS. Показывается один раз за сессию (`sessionStorage cm_boot`), минимум 1.9 с, максимум 4.5 с, CSS-предохранитель прячет его через 7 с даже без JS. Счётчик докручивается до максимального зазора в каталоге.

## Деплой

Vercel, проект `eugenazxas-projects/carmarketspb`, временный домен **https://carmarketspb.vercel.app**. Деплой из папки: `vercel deploy --prod` (CLI в `~/.local/node/bin`, вход eugenazxa). Git-интеграция не подключена, пуш в GitHub сам не выкатывает.

Пока домен временный, сайт закрыт от индексации: `X-Robots-Tag: noindex` в `vercel.json`, `robots.txt`, `<meta name="robots">`. Перед запуском на боевом домене убрать все три. `tools/` и README на сервер не уходят (`.vercelignore`).
