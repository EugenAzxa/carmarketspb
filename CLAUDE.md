# CarMarket SPB

Маркет машин от медийных перекупов Петербурга (Lex Auto, Перекупчино). Статический сайт без сборки, деплой на Vercel.

**Перед работой прочитай `notes/STATUS.md`**, там текущее состояние, ссылки и порядок действий. Грабли - в `notes/GOTCHAS.md`.

Правила:
- В текстах сайта только короткие дефисы, без длинных тире и без эмодзи; иконки - SVG.
- После правок CSS/JS подними `?v=N` во всех 4 HTML.
- `assets/js/cars.js` и `assets/js/cars-perekupchino.js` генерируются скриптами из `tools/`, руками не править.
- Локально: `python3 -m http.server 8811`. Деплой: `vercel deploy --prod`.
- Сделанное записывай в `notes/LOG.md`, решения - в `notes/DECISIONS.md`, состояние - в `notes/STATUS.md`.
