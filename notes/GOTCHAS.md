# Грабли, на которые уже наступили

## Сайт

- **Кэш браузера.** После правок CSS/JS поднять `?v=N` в подключениях во всех 4 HTML (`sed -i '' -E 's#\?v=16"#?v=17"#g' *.html`). Иначе браузер и service worker покажут старое.
- **Загрузочный экран** (`#boot`) вставлен прямо в каждый HTML (стиль в `<head>`, разметка в начале `<body>`), чтобы появлялся до загрузки CSS. Меняешь его - меняй во всех 4 файлах одинаково. Показывается раз за сессию (`sessionStorage cm_boot`), для проверки чистить sessionStorage на том же домене.
- **Грид и переполнение на телефоне**: колонки `1fr` раздуваются от широких лент (галерея, посты Telegram). Использовать `minmax(0, 1fr)` и `min-width: 0` у детей. Проверять `document.documentElement.scrollWidth === 390`.
- **CSS-классы окрасов** называются `s-n / s-p / s-u`, не `n / p`: класс `p` совпадал с базовым `.p` и красил всю схему.
- **Пустая схема окрасов**: `allNative` требует хотя бы один элемент, иначе у машин без данных появлялась ложная плашка "Родная краска".
- **Стили, которые нужны на любой ширине, не прятать в `@media`** (так "голой" вылезла плашка "Установить").
- **Без длинных тире и эмодзи в интерфейсе**, иконки только SVG. Перед коммитом: `grep -c '—' *.html assets/js/*.js`.

## Скриншоты и проверка

- Headless Chrome врёт: анимации не идут, ширина телефона не применяется. Рабочий способ: видимый Chrome с `--remote-debugging-port=9333` и управление через CDP из Node без зависимостей (`Emulation.setDeviceMetricsOverride` для телефона, `Page.captureScreenshot`).
- Если окно Chrome закрыто другими окнами, вкладка "засыпает": анимации стоят, ленивые ленты не грузятся. Запускать с `--disable-backgrounding-occluded-windows --disable-renderer-backgrounding --disable-background-timer-throttling`.

## Данные

- **Instagram из нашей сети недоступен** (соединение рвётся даже вне песочницы). Фото и рилсы оттуда не взять, только ссылка на профиль.
- **Встроенные посты Telegram** работают только для публичных каналов. Для закрытого канала Перекупчино встраивания нет. Видео в виджете часто "Media is too big" - это ограничение Telegram.
- **Telegram Web (K) держит в DOM только ~12 постов** и выкидывает новые при прокрутке вверх. Собирать посты нужно по ходу прокрутки. Прокрутку делать через `.bubbles-scrollable.scrollTop` + событие `scroll`, колесо мыши не всегда срабатывает.
- **Чтение залогиненного Telegram** система безопасности Claude Code блокирует в авто-режиме (личные данные). Работает только в ручном режиме с явным подтверждением владельца аккаунта. Читать только нужный канал, не список чатов. После работы завершить сессию в Telegram -> Настройки -> Устройства.
- **Посты Перекупчино неоднородны**: цена бывает "💰450.000₽" без слова "цена", пробег "164 тыс. км", марка с опечаткой "YAZ PATRIOT", русская С в "300С". Всё это учтено в `build_perekupchino.py`.
