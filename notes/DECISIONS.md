# Ключевые решения и почему

| Решение | Почему | Когда пересмотреть |
|---|---|---|
| **Статика без сборки**: HTML + один CSS + один `app.js`, данные в `assets/js/cars*.js` | Быстро показать идею, хостинг почти бесплатный, нечему ломаться | Когда появятся задатки, аккаунты, импорт в реальном времени - нужен бэкенд |
| **Данные из Telegram-каналов продавцов**, а не ручной ввод | Продавцы уже публикуют машины там. Наш главный аргумент для блогеров: "твои посты уже объявления" | Перейти на бота-админа в канале: новые посты приходят сами |
| **"Зазор до рынка" как главная цифра** | Это язык самих перекупов и главный повод купить | - |
| **Тема на продавца** (`theme` в `sellers.js`: `neon`, `grunge`) | Блогерам важен свой бренд, покупатель сразу видит, чья машина | Новые продавцы - новые темы по их логотипу |
| **Рамка номера с логотипом** (`.plate`) на каждой карточке | Так выглядят машины Lex Auto в жизни (рамка "ЛЕКСАВТО") | - |
| **Характеристики дополняются в браузере** (`enrich()` в `app.js`): кузов и привод по модели, бензин по умолчанию при указанном объёме, цвет только если написан | Посты продавцов неполные, а фильтры нужны. Одна функция работает для всех источников | Если продавцы начнут заполнять поля сами |
| **Задаток и торг без реальной оплаты**, заявка дублируется продавцу в Telegram | Демо: показать механику, не принимая денег и персональных данных | Бэкенд + платёжка (СБП дешевле карт) + хранение в РФ (152-ФЗ) |
| **Счётчики "хотят купить" и "смотрят сейчас"** считаются от реальных просмотров поста, но не живые | Показать идею спроса | Живые цифры с бэкенда |
| **2 проданные машины Перекупчино** = 2 самых старых из 17 | В канале не видно, какие ушли | Когда продавец отметит сам |
| **Схема окрасов приблизительная** у Lex Auto | Продавец пишет "2 окраса", но не где | Продавец заполняет толщиномер по элементам |
| **Тёмная тема, лайм `#c8ff2e`, Unbounded + Manrope** | Хайп, контраст, кириллица в обоих шрифтах | - |
| **Короткие дефисы, без длинных тире и эмодзи в UI**, иконки SVG | Требование Евгения: длинные тире и эмодзи выглядят как ИИ | Не пересматривать |
| **Мобильная версия как приложение** (нижнее меню, PWA) | Аудитория в Telegram с телефона | - |
| **Vercel, деплой CLI, без Git-интеграции** | Быстро получить ссылку | Подключить автодеплой из GitHub, когда будет стабильно |
| **noindex на временном домене** | На сайте фото, телефоны и бренды блогеров без их согласия | Снять при запуске на боевом домене |
| **Бэкенд в РФ** (когда появится) | 152-ФЗ: персональные данные граждан РФ хранить в РФ. Vercel / Cloudflare из РФ работают нестабильно | - |
